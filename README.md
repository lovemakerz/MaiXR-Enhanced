# MaiMaiVR - Enhanced

Enhanced VR arcade experience for **maimai DX**, based on [MaiDXR](https://github.com/xiaopeng12138/MaiDXR).

> **MaiMaiVR - Enhanced is built on top of MaiDXR and keeps full credit to the original project and its contributors.**
>
> Original MaiDXR project:
> https://github.com/xiaopeng12138/MaiDXR

---

## About

MaiMaiVR - Enhanced extends MaiDXR with additional features focused on:

- NATIVE IO !!!
- Support Internationnal and Japanese version
- easier setup
- improved VR interaction
- more reliable rhythm-game touch detection
- automatic COM configuration
- multi-installation game management
- improved spectator usage
- portable/offline distribution

The goal is to make the experience as close as possible to using a real maimai DX cabinet while remaining easy to install and use on a home VR setup.

---

## Main Features

### Original MaiDXR features

MaiMaiVR - Enhanced keeps the core features provided by MaiDXR:

- Support for maimai DX versions
- Cabinet model close to the original DX cabinet
- Native touch input
- LED output
- 90 Hz / 120 Hz game capture
- Customizable controller haptics
- Third-person / spectator camera
- Smooth camera movement
- Customizable buttons
- Player 1 / Player 2 support
- In-game configuration panel
